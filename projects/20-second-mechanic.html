Overview

The Thingimajig™ Machine needs maintenance, fast! Fix it before it blows up!
Developed for the 20 Second GameJam 2026, 20 Second Mechanic is a short, fast-paced puzzle microgame where players fix a weird machine by replacing parts, plugging in wires, and calibrating dials across levels before time runs out.

I wanted to make a short experience with this type of interaction for a while, and this game jam gave me the perfect opportunity to try it out. My goal was to make a silly physics-based grab system that supported the hectic nature of the jam. The timing on completing all the levels is very tight, but with the ability to quickly restart, players can practice and get better at all the various types of challenges. There are some elements of randomization in the order and layout of the levels to keep players guessing. Some challenges require fast reactions while others need a more careful hand.

For the art, I worked together with a friend, who provided me with some concept and vector art. I used these Assets as a style-guide to create the rest of the graphics in Affinity. The rest of the game was created in Unity. This is the first project in a while where I had no programmer support, but it turned out pretty good, I think. I managed to create some reusable scripts for scene loading, input reading, and playing audio, and I really like how the interaction system feels.

All in all, I am very happy with how this turned out. Since this was a longer jam, I could work on this project for around 3 weeks, on and off. This allowed me to reach a level of polish I am very happy with!
